# TrendGuard-200-Multi-Asset-Algorithmic-Trading-Framework
1. Executive SummaryThis project develops and backtests a vectorized algorithmic trading strategy applied to a diversified portfolio of equities over an 8-year horizon. The core objective was to solve the "Whipsaw" problem—where trend-following indicators lose money in sideways or bear markets.By implementing a Long-term Regime Filter (200-SMA), this strategy successfully avoided major liquidity shocks (2020 COVID Crisis), delivering superior risk-adjusted returns (Sharpe Ratio > 1.3).
2. The Strategy Logic (Triple-Filter System)The algorithm executes trades based on three synchronized mathematical conditions:Regime Filter: Price must be above the 200-day Simple Moving Average. This ensures we only trade in structural bull markets.Momentum Trigger (Golden Cross): Entry occurs when the 21-day SMA crosses above the 50-day SMA.Exit Logic: Exit occurs immediately when the 21-day SMA crosses below the 50-day SMA, preserving capital before major reversals.
3.  Technical ArchitectureThe project is built using a modular Quantitative Research Pipeline:Data Engine: Automated ETL pipeline that synchronizes disparate CSV time-series using outer joins and forward-fill imputation.Signal Factory: Vectorized logic using NumPy and Pandas for high-performance signal generation ($O(n)$ complexity).Analytics Engine: Calculates institutional metrics including Annualized Sharpe Ratio, Maximum Drawdown, and Win Rate.
